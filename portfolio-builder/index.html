안 보이면 ① 카톡·인스타 안이 아닌 크롬·사파리에서 열었는지 ② 폰이면 PC에서 다시 시도 ③ 그래도 안 되면 지금 화면을 캡처해 수업 때 가져오세요. 작업 내용은 이 브라우저에 저장돼 있습니다.

zip 안에 index.html, img 폴더, 안내문, 작업 데이터가 들어 있습니다. 이 zip을 다시 1단계에 올리면 이어서 수정할 수 있습니다.

GitHub에 올리는 방법

  1. GitHub 가입github.com에서 Sign up. 아이디는 영문 소문자로 정하세요. 이메일 인증까지 마칩니다.
  2. 저장소 만들기오른쪽 위 + → New repository → 이름에 아이디.github.io → Public → Add README는 켜지 않기 → Create repository
  3. 파일 올리기내려받은 zip을 풀고, 빈 저장소 화면의 uploading an existing file을 누른 뒤 폴더 안의 index.html과 img 폴더를 함께 끌어다 놓습니다.
  4. 저장업로드가 끝나면 아래 초록색 Commit changes를 누릅니다.
  5. Pages 켜기Settings → 왼쪽 Pages → Branch를 main / /(root)로 → Save. 이미 켜져 있으면 그대로 둡니다.
  6. 주소 확인1~3분 뒤 위의 주소로 접속합니다. 고칠 때는 다시 내려받아 3~4번처럼 덮어 올리면 됩니다.
